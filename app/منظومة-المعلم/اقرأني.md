# منظومة المعلم — الإصدار ٥٤

## المحتويات

| المجلد | الاستخدام |
|---|---|
| `١-للنشر/` | ارفع محتواه على Cloudflare Pages أو Netlify |
| `٢-الملف-المفرد/` | نسخة واحدة للأرشفة أو المشاركة |
| `٣-قاعدة-البيانات/` | أكواد SQL تُنفَّذ في Supabase |
| `٤-أدلة/` | أدلة الربط والتوصيات |

## النشر

1. افتح Cloudflare Pages ← Create ← Upload assets.
2. ارفع **محتويات** مجلد `١-للنشر` (الملفات الثلاثة) — لا المجلد نفسه.
3. افتح الرابط الناتج.

> المهم: افتح النظام من **الرابط المنشور** دائمًا، لا من الملف مباشرة.

## قاعدة البيانات (مرة واحدة)

Supabase ← SQL Editor ← New query ← الصق `أكواد-Supabase.sql` كاملًا ← Run.
النتيجة المتوقعة: `Success. No rows returned`.

هذا الملف ينشئ:
- جدول المزامنة `teacher_data`
- جداول بوابة ولي الأمر ودوالها
- دالة `evidence_view` لبوابة الشواهد المعزولة
- صندوق التخزين `evidence` لمرفقات الشواهد

## بعد النشر

1. ادخل بحسابك.
2. الشواهد ← بوابة الشواهد ← **تحديث البوابة** (يرفع مرفقاتك للسحابة).
3. **اطبع رموز QR من جديد** — الرموز المطبوعة سابقًا تحمل روابط قديمة.

## التحقق من الاتصال

صفحة متابعة الطالب ← زر **تشخيص الاتصال**. يجب أن تظهر البنود الأربعة ✅:

```
teacher_data      ✅
guardian_publish  ✅
evidence_view     ✅
storage evidence  ✅
```

## ما في هذا الإصدار

- حفظ سحابي فوري مع إعادة محاولة تلقائية عند عودة الاتصال
- تخزين موسّع بـ IndexedDB مع ضغط الصور — لا رسالة «تعذّر الحفظ»
- دخول فوري لا ينتظر الشبكة
- تخطيط Flexbox يعمل محليًا ومنشورًا
- بوابة ولي الأمر: تعهّد، سلوك «أخرى» بتفاصيله، هوية اليوم الوطني
- بوابة شواهد معزولة لكل معيار بباركود مستقل
- حذف سجلات المشاركة والسلوك
- إعادة ظهور التعهّد عند حذفه من سجل المتابعة
